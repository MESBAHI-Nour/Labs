# Lab 02 — Création de Skills pour Agents IA

- **Sujet :** Conception et implémentation de Skills pour Agents IA (structure SKILL.md, métadonnées YAML et règles d'automatisation)
- **Modules/unités :** Veille & Automatisation IA (T1.U1 / T1.U2)
- **Description :** Guide pratique pour concevoir, structurer et tester un Skill personnalisé pour agents d'intelligence artificielle dans un environnement de développement.

## Objectifs d’apprentissage
- Comprendre le rôle et l'architecture des Skills dans les agents IA modernes (Antigravity, Gemini).
- Structurer un dossier de Skill conforme avec son fichier pivot `SKILL.md` et son frontmatter YAML.
- Rédiger des règles d'activation précises pour orienter le déclenchement de l'agent.
- Créer un premier Skill simple de validation (Hello World).
- Développer un Skill complet Quick Start (`commit-helper`) automatisant les bonnes pratiques de développement.
- Tester et vérifier la prise en compte du Skill par l'environnement d'agent.

## Prérequis
- Un environnement d'agent IA supportant les compétences locales (dossier `.agent/skills/` ou équivalent).
- Un éditeur de code (VS Code ou Antigravity IDE).
- Connaissances de base de la syntaxe Markdown et du format YAML.
- Notions élémentaires sur l'utilisation de Git et des invites de commande.

## Parcours du lab
1. Définition
2. Outils et installation
3. Hello World ou première pratique
4. Quick Start
