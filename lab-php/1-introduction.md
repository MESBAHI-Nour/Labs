# Introduction

## Contexte
Une application doit signaler les données invalides, garder ses classes organisées et éviter de répéter du code.

## Importance du sujet
Les exceptions rendent les échecs prévisibles ; les namespaces clarifient l’organisation ; les traits partagent des méthodes entre classes.

## Objectifs pédagogiques
- Détecter une donnée invalide et lancer une exception adaptée.
- Intercepter l’exception sans interrompre silencieusement le programme.
- Déclarer et importer un namespace.
- Partager une méthode entre deux classes avec un trait.
- Exécuter et vérifier une mini-application PHP.

## Parcours du lab
1. Définir les notions et préparer PHP en ligne de commande.
2. Exécuter un Hello World.
3. Construire puis tester le Quick Start multi-fichiers.
